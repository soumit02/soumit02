## 🚀 Featured Projects

### 🧭 [Jibon Shohayok – AI Life-Admin Assistant for Bangladesh](https://github.com/soumit02/Jibon-shohayok)

A bilingual (Bangla/English) assistant that helps people in Bangladesh track document expiry dates, understand official procedures, and plan trips within a budget.

- Multi-agent architecture using **CrewAI**, with four specialized crews: Document, Procedure Guide, Planning, and Action
- **RAG** with ChromaDB and Gemini Embeddings over official government PDFs, with source citations
- Tool calling, budget-aware trip planning, and primary/backup LLM fallback
- FastAPI backend with JWT authentication, containerized with Docker and deployed on Render

🔗 [GitHub](https://github.com/soumit02/Jibon-shohayok) · [Live Demo](https://jibon-shohayok.onrender.com) · [API Docs](https://jibon-shohayok.onrender.com/docs)

### 🎓 [Leo – Multi-Agent AI Tutor](https://github.com/soumit02/Leo-Multi-Agent-Educator)

An interactive tutoring platform where specialized AI agents teach a topic, generate a quiz, grade the answers, and re-teach with simpler explanations when needed.

- Four specialized **CrewAI** agents: Coordinator, Explainer, Quiz Master, and Evaluator
- Hierarchical and sequential orchestration with a **human-in-the-loop** quiz workflow
- Automatic re-teaching with simpler explanations after incorrect answers
- LLM fallback and a live agent-status dashboard

### 📚 [Bangla Knowledge Base Chatbot (RAG)](https://github.com/soumit02/Bangla-Knowledge-Base-Chatbot)

A Retrieval-Augmented Generation chatbot that answers questions about the Bangla novel *Mejdidi* only from the book itself.

- **LangChain** and **ChromaDB** with **BAAI/bge-m3** multilingual embeddings
- Grounded question answering with chapter citations
- Hallucination reduction through a strict grounding prompt and retrieval-based answering

### 💵 [Bangladeshi Taka Note Prediction System](https://github.com/soumit02/Bangladeshi-Taka-Note-Detection-)

An end-to-end computer vision web app and REST API that detects and classifies Bangladeshi banknotes from an uploaded image.

- Fine-tuned **YOLOv11n** (Ultralytics) for banknote object detection
- **FastAPI** `/predict` endpoint returning denomination, confidence score, and bounding box
- **Redis** caching and **Nginx** load balancing, containerized with **Docker Compose**

🔗 [GitHub](https://github.com/soumit02/Bangladeshi-Taka-Note-Detection-) · [Live Demo](https://bangladeshi-taka-note-detection-mchz.onrender.com)
